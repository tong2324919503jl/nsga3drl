MTSP（多旅行商问题）是经典旅行商问题的扩展，即为多车规划最优路径、使他们共同高效地访问所有指定地点。近年来，随着深度学习的发展，MTSP逐渐成为研究热点。然而，传统算法大都聚焦单一目标、对起点终点有统一要求、忽略动态适应性、未运用结构化信息，面临复杂实际问题时仍有提升空间。
本研究聚焦于更贴合实际的问题设定：1. 假定各车无统一仓库、无闭环要求；2. 配送途中会动态加点；3. 考虑任务分配总体效率性与公平性，多目标权重参考用户偏好。逐步深入探索问题求解方案。
在路径规划方面，本研究将在融合元启发式算法的同时引入图神经网络与多层感知机，设计多模态特征融合编码器实现路网拓扑、用户偏好和当前种群三类特征自适应融合，设计深度强化学习策略网络，在元启发式算法的遗传环节引导父代与算子选择，从而实现最优路径规划；在目标函数方面，分别以总路程与各路径长度方差衡量总体效率与公平性，通过用户偏好对多目标加权以设计总体目标；在动态加点方面，将利用KD-Tree筛选范围并综合效率与公平科学化分配新增目标。
最后，本项目将兼顾运行效率与优化质量进行实验对比，形成可迁移的技术方案。
研究目标：聚焦动态非闭环场景，提出针对性求解框架
现实世界中的多模态动态协同调度是一个极其复杂的巨系统，受制于TSP/MTSP问题本身的NP-Hard属性，本研究不可能彻底解决所有现实场景下的调度难题。
因此，本项目的研究目标集中于一点：针对真实场景中“无统一仓库、无闭环要求、高频动态加点”这一核心痛点，提出一套基于多模态DRL引导的多目标进化求解方法，并对其进行深入探讨与验证。
具体而言，本研究旨在：
1.构建简化模型：剥离传统研究中不切实际的“闭环”与“单起点”假设，建立兼顾“整体效率”与“负载公平”的双目标非闭环MTSP数学模型。
2.提出求解方法：设计并实现一套融合GNN、Transformer与DRL的混合优化框架，利用多模态数据驱动策略替代传统启发式算法中的人工规则，提升算法在动态环境下的求解精度与响应速度。
3.验证与探讨：通过仿真实验探讨该方法在不同规模、不同动态加点频率下的表现边界，为新一代即时配送与网约车调度提供切实可行的算法参考。
二）研究内容
为实现上述研究目标，本项目将开展以下核心研究内容：
1.	双目标多车路径规划问题建模与编码
•	明确问题约束：无统一起终点、不重复访问、支持动态新增途经点。
•	建立双目标优化函数：f1 = 最小化总行驶距离；f2 = 最小化各车辆路径长度的方差。
•	设计整数分段编码方案，以简洁有效地表示“车辆分配”与“访问顺序”的解。

2.	面向路径规划问题的状态特征编码器设计
•	设计图神经网络编码器，用于提取途经点空间布局与距离关系的拓扑特征。
•	设计种群状态编码器，通过多层感知机（MLP）提取当前优化种群的分布、收敛性等数值特征。

3.	DRL引导的NSGA-III混合算法核心机制设计
•	DRL策略网络设计：以融合后的特征（图特征+种群状态特征）为输入状态，输出两个核心决策：①从种群中选择哪两个解作为父代（父代选择）；②对所选父代应用何种交叉算子与变异算子。
•	奖励函数设计：以算法单次迭代后，种群帕累托前沿超体积（HV）的改进量为核心奖励信号，引导DRL学习能持续提升解集质量的策略。
•	算法融合框架：将上述DRL智能体嵌入NSGA-III的主循环中。在每一代，由DRL决策选择父本与算子，生成子代；再由NSGA-III执行快速非支配排序、参考点选择等标准流程，维持种群多样性与进化压力。

4.	动态加点增量式优化策略
KD-Tree加速邻近点搜索：新增途经点后，首先利用KD-Tree快速定位距离最近的K个未访问目标点，避免全局距离计算，显著提升动态场景下的计算效率；
KNN顺路分定义：基于K个邻近点，统计每辆车在这些点中负责的目标点数量，数量越多说明该车与新点越“顺路”，赋予顺路分；
均衡分定义：根据每辆车当前已行驶总路程，定义均衡分，总路程越低则均衡分越高，体现负载均衡目标；
总分分配机制：每辆车总分 = 顺路分 × 均衡分，将新目标点分配给总分最高的车辆，并依据其原始路径顺序插入最优位置；
局部路径调整：仅对插入新点后的局部路径进行微调，避免全局重算，确保实时性与优化质量的平衡

5.	实验验证与性能评估体系构建
•	数据集构建：模拟生成不同规模（车辆数、途经点数）的测试实例，并预设多组不同的目标权重（如[0.9,0.1], [0.5,0.5]）以代表不同偏好。
•	对比实验设计：将所提混合算法与标准NSGA-III、随机算子选择的NSGA-III等基准进行对比。
•	评估指标：采用超体积、世代距离（GD） 评价解集收敛性与多样性；记录运行时间评价效率；分析在不同权重下算法结果的差异，验证其适应性。
1.	双目标开放型 MTSP 问题建模与编码实现
首先完成问题的数学建模与解的编码设计，为后续算法设计奠定基础。针对项目场景的 “无统一仓库、无闭环、支持动态加点” 特性，我们将建立开放型多旅行商问题的约束体系，明确 “途经点不重复访问、车辆路径有序” 的核心约束，同时构建双目标优化函数：以总行驶距离最小化作为效率目标，以车辆路径长度方差最小化作为公平目标，剔除冗余的单车最长路径目标，降低优化复杂度。在此基础上，设计整数分段编码方案，通过分隔符实现车辆分配与访问顺序的联合编码，保证解的合法性，同时支持快速解码与目标函数计算，为后续进化算法的迭代提供高效的解表示。

2.	多模态状态特征编码器构建
针对 DRL 智能体的决策需求，我们将构建三类模态的特征编码器，并实现自适应融合。首先，针对路网的图结构特性，采用图注意力网络作为图模态编码器，通过注意力机制捕捉途经点的空间关联与距离特征，自动为不同距离的节点分配权重，精准提取路网拓扑特征；其次，针对种群状态，设计基于多层感知机的种群编码器，将当前种群的超体积、目标均值、拥挤度等数值特征编码为固定维度的向量，反映算法的当前优化状态；最后，针对用户偏好，设计轻量嵌入层，将用户的双目标权重偏好编码为偏好特征向量，实现对用户需求的适配。在此基础上，采用交叉注意力融合机制，实现三类模态特征的自适应融合，自动学习不同场景下各模态的权重，为 DRL 智能体提供全面、精准的状态输入。

3.	DRL 引导的 NSGA-III 混合算法核心实现
这是本项目的核心创新模块，我们将实现 DRL 与 NSGA-III 的深度融合。首先，基于 pymoo 框架搭建标准 NSGA-III 的基础框架，实现非支配排序、参考点生成、环境选择等核心流程，作为算法的进化骨架。其次，构建基于 PPO的 DRL 智能体，将 NSGA-III 的迭代过程建模为马尔可夫决策过程，以融合后的多模态特征作为状态输入，输出父代选择概率分布与进化算子选择概率分布，替代传统人工固定规则。其中，父代选择环节，DRL 将根据种群状态自适应选择最优父代个体，平衡种群的收敛性与多样性；算子选择环节，DRL 将根据迭代阶段自适应选择交叉、变异、2-opt 局部搜索等算子，动态调整进化策略。最后，设计以超体积改进量为核心的奖励函数，引导 DRL 学习最大化累计奖励的最优策略，实现对 NSGA-III 进化过程的智能引导，提升算法的搜索效率与解集质量。

4.	动态增量式优化策略设计
本研究在动态加点后，会首先根据数据规模，利用KD-Tree寻找离新增目标点最近的K个未访问目标点，避免计算新增目标点到每个点之间的距离；再利用KNN为这K个点的负责车定义“顺路分”，车在这K个点里负责的点越多分越高；后根据这几辆车各自总行驶路程定义各自的“均衡分”，总路程越低均衡分越高；每辆车总分定义为顺路分与均衡分之积，最后将新目标分配给总分最高的车并根据其原始路径决定安插位置。

5.	实验验证与性能评估
最后，我们将构建完整的实验体系，验证算法的有效性。首先，构建多规模的测试数据集，模拟不同车辆数、途经点数的场景，同时设置多组用户偏好权重，覆盖不同的用户需求。其次，设计对比实验，将本项目提出的混合算法，与标准 NSGA-III、随机算子选择的 NSGA-III 等基准算法进行对比，从收敛性、多样性、运行时间三个维度进行评估。最后，采用超体积、世代距离、间距等多目标优化评价指标，量化算法的解集质量，同时分析算法在不同偏好权重、不同问题规模下的鲁棒性，为算法的工程应用提供支撑。
